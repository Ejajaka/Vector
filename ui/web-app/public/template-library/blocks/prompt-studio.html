UI Specification & PromptDraft v.04
01 / Context

Build a responsive analytics dashboard for ops leads and finance admins. The screen should feel quiet, data-first and trustworthy.

02 / Layout

Fixed top navigation; collapsible left sidebar; content area with four KPI cards, a full-width 30-day trend chart and a recent-orders table. Stack KPI cards 2-up below 768px.

03 / Components

KPI card x4 with label, value and delta. Trend chart with line + area and a 7/30/90-day selector. Recent orders table with search, filter and CSV export.

04 / Interaction

Date range changes the chart in place. Export downloads the visible range as CSV. Empty states explain how data appears. Errors are inline and retryable.
