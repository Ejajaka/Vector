Good prompts don't always mean secure infrastructure.

        
When developers or operators prompt AI or code generators for cloud infrastructure, requests typically focus on functional requirements (e.g. "create a public S3 bucket", "open SSH access", "connect EC2 to RDS").

        
Crucial non-functional security controls are routinely omitted: at-rest encryption, restrictive security groups, IMDSv2 tokens, least-privilege IAM roles, access logging, and secure defaults. Once code is generated, fixing misconfigurations requires expensive audits and refactoring.

Analysis Approach

        
Vector uses deterministic NLP and rule-based analysis to examine infrastructure prompts and identify supported AWS resources and security-related patterns.

        
All core pattern extraction, resource detection (EC2, S3, RDS, ALB, VPC, IAM), and severity classifications run 100% on-device. Prompts remain completely confidential and never leave your device.

      


      

        
A useful checkpoint, not a security guarantee.

        
Findings depend on the prompt text, supported AWS resources, implemented security rules, and available context. Prompt analysis cannot fully validate deployed infrastructure, runtime behaviour, network boundaries, or an entire AWS environment.

        
Always review recommendations, perform automated infrastructure-as-code linting (e.g., checkov, tfsec), and validate generated infrastructure prior to production deployment.
