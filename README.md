# Vector

**Pre-generation security diagnosis of AWS infrastructure prompts using NLP.**

Vector reads a natural-language AWS infrastructure prompt *before* code is
generated, flags the security constraints the prompt omitted, and turns each one
into a ready-to-add clause. The core engine is deterministic, rule-based NLP -
no ML model, no network calls, zero npm dependencies.

## Repository layout

```
engine/     the shared NLP engine (the product)
  src/        taxonomy.js, analyzer.js, semantic.js, llm.js, tfcheck.js,
              settings.js, ui.js/.css
  cli/        vector-cli.js  (analyze / improved / verify / hook)
  eval/       labelled datasets + metrics;  test/  unit tests
ui/         all clients - each one calls the SAME engine
  extension/    Chrome/Edge MV3 extension (popup, in-page panel, options)
  web/          static web demo (GitHub Pages)
  web-app/      React + Vite web client
  mobile-expo/  React Native (Expo)
  mobile-native/Capacitor Android app (wraps the web client)
  android/      native Kotlin + Jetpack Compose Android app
  store/ media/ store-listing assets + brand icons
docs/       deliverables (Vector-*.docx) + _sources/ markdown originals
tools/      build scripts (icons, packaging, engine sync, doc generation)
```

## Brand

The Vector logo is a dark-green tile (`#2D5D4F`) with a gold V (`#FACB43`).
Every icon, launcher and splash is generated by `tools/make-icons.js`.

## Run

Requires Node.js (engine, CLI, web, tooling). Android builds additionally need
the Android SDK / Gradle.

```powershell
# Engine: unit tests + evaluation
npm test
npm run eval

# CLI
node engine/cli/vector-cli.js analyze "Create an S3 bucket and an EC2 instance"
node engine/cli/vector-cli.js improved "Create an S3 bucket"

# React web client (ui/web-app)
npm run webapp:install     # first time only
npm run webapp             # dev server -> http://localhost:3000

# Package the browser extension -> dist/vector-extension.zip
npm run package

# Regenerate brand icons / Word documents
npm run icons
npm run docs
```

## Documentation

All deliverables live in `docs/` as Word documents; the markdown sources are in
`docs/_sources/`. Recommended reading order: `MARKET-ANALYSIS` (why) ->
`ARCHITECTURE` (how) -> `ROADMAP` (plan) -> `COURSE-PLAN-MAPPING` (syllabus).
