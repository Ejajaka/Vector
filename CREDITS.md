# Credits & Attribution

## Vector (this repository)
The core rule-based NLP engine (`engine/`), the command-line client
(`engine/cli/`), the evaluation harness (`engine/eval/`), the browser extension
(`ui/extension/`), the static web demo (`ui/web/`), the Expo and Capacitor
mobile clients (`ui/mobile-expo/`, `ui/mobile-native/`), the documentation
(`docs/`) and the build tooling (`tools/`) are the Vector project.

## Contributed UI clients
- **React web client** - `ui/web-app/` - UI contributed by teammate
  **Satya Sree Pada** (github.com/satyasreepada1101). The layout, components and
  styling are theirs; all data now comes from the shared `engine/src` (the
  original hardcoded/demo data was removed).
- **Native Android client** - `ui/android/` - Kotlin + Jetpack Compose UI also
  contributed by Satya Sree Pada.

Both of the above were originally scaffolded from Google's **AI Studio**
repository template (`google-gemini/aistudio-repository-template`).

## Brand
The Vector logo (dark-green tile `#2D5D4F` with a gold V `#FACB43`) and all
derived icons/splashes are generated by `tools/make-icons.js`.
